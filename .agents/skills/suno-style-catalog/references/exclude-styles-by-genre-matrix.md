# Matriz de Exclusiones Negativas por Género para Suno V6

En Suno V6, el casillero **Exclude Styles** opera como un filtro estocástico.
* **Regla 1:** Mantener la lista siempre en **menos de 8 a 10 categorías**. Listas gigantescas degradan el audio o confunden al modelo.
* **Regla 2:** Usar solo nombres de familias instrumentales o géneros ajenos (sustantivos). Jamás usar oraciones ni adjetivos cualitativos (*"loud", "fast", "bad"*).
