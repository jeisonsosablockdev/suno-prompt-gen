# Base de Datos de Exclusiones Negativas (`Exclude Styles`)

Las exclusiones negativas en Suno impiden que el modelo meta instrumentos acústicos no deseados o estilos comerciales que diluyan el sonido de club.

---

## 1. Exclusión Universal para Club Underground
Este bloque debe incluirse por defecto en cualquier pista de House, Techno, Tech House, Melodic o Indie Dance:

```text
EDM, Big room, Commercial Pop, Radio Pop, Acoustic Guitar, Classical Guitar, Banjo, Accordion, Harp, Ukulele, Brass Section, Big Band Horns, Orchestral Strings, Country, Slap House, Distorted Metal, Rock Drums, Heavy Metal Vocals, Operatic Vocals, Broadway Musical
```

---

## 2. Exclusiones Específicas por Subgénero

### Para Tech House / Minimal:
```text
EDM, Big room, Melodic Trance, Epic Strings, Orchestral Pads, Pop Vocals, Acoustic Drums, Piano Ballad, Rock Guitars, Cheesy Synths, Eurodance
```

### Para Melodic House / Techno:
```text
Aggressive Dubstep, Trap 808, Hip Hop Beat, Screaming Vocals, Country Banjo, Polka Accordion, Radio Pop Vocals, Dry Funk Slap Bass, Happy Hardcore
```

### Para Dark Disco / NY House:
```text
Festival EDM, Big Room Drops, Dubstep Wobble, Death Metal, Acoustic Country, Rap Verse, 90s Eurodance, Chipmunk Vocals, Distorted Guitars
```

### Para Peak Time / Acid Techno:
```text
Pop Melody, Sweet Vocals, Acoustic Instruments, Jazz Piano, Reggaeton Dembow, R&B Harmonies, Tropical House Marimba, Cheesy Horns
```
